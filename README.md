# MSCS532 Assignment 1: Insertion Sort (Decreasing)

Python implementation of the Insertion Sort algorithm from Chapter 2 of
Cormen, Leiserson, Rivest & Stein, *Introduction to Algorithms*
(4th ed., 2022).

The textbook version sorts in increasing order; this assignment sorts the
list into **monotonically decreasing** order.
